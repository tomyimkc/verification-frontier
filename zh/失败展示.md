# 失败案例展示

> 手册明确，若**过程与洞见可解释，则允许负向结果**。本包以失败作为**完整性证据**先行，而非能力证据。此处无任何失败被隐藏或重试以伪造更干净的数字。

## 1. 保留的格式错误 JSON 响应（Stage A）

- **家族：** `stage-a-lean-01-executable-contract`
- **错误：** `malformed JSON at line 6 column 70: Invalid control character`（Lean 形式化 JSON 字段中一个未转义换行）。
- **处置：** **作为无效保留**，不重试。24 家族结果因此为 **23/24**，并在 `v2/artifacts/stage-a-development-result.json` 中不可变披露。
- **为何重要：** 一个悄悄重试格式错误响应直至命中 24/24 的项目，报告的是采样运气，而非结构化输出合规。格式错误行**正是**解析器真实且失效闭合的证据。
- **信号类型：** 失效模式 + 稳定负向（解析器拒绝，且拒绝在规范字节检查中保留）。

## 2. 暖缓存存储准入失败（首次 24 家族尝试）

- **运行：** `30729611283`（精确 head `d2daa02911…`）
- **发生了什么：** 成功的 3 家族 smoke 填充了持久 15.24 GB 模型缓存，剩余约 21.0 GiB 空间——低于 32 GiB 冷缓存准入地板。运行在初始存储门**停止，早于任何 GPU 申请、CUDA 接触、模型接触、revision 解析、权重加载或提案生成**。
- **receipt：** `gpuClaimed:false`、`gpuReleased:false`、`modelRevision:null`、`status:failure`。
- **修正（已合并 PR #1813）：** 存储门现区分冷缓存 `preflight`（32 GiB 地板）与开发 `stage-a-run`（20 GiB 运营储备），同时保留权威主机门 `ceil(1.20 × missingBytes + 4 GiB)` 于任何模型权重加载之前。
- **信号类型：** 异常 + 合理问题修正（门停止是对的；**地板策略**才是 bug）。

## 3. 依赖解析失败（两次 preflight）

- **运行：** `30724109619` 然后 `30725934502`
- **发生了什么：** `transformers==5.13.1` 要求 `huggingface-hub>=1.5.0,<2.0` 与 `safetensors>=0.8.0`；合并的 requirements 固定了不兼容的旧版本。两次 preflight 在 `pip` 解析阶段失败，**早于任何主机/模型可行性或提案步骤**；`modelRevision:null`；未发生模型加载。
- **修正（已合并 PR #1808、#1810）：** Python 3.12 pip-resolver 干运行以合成的预装 Torch 闭合了完整 29 包依赖集。此后 preflight `30727627325` 成功。
- **信号类型：** 失效模式 + 反例（单 pin 盲重试无效；完整依赖闭包有效）。第三次 preflight 明确以闭包修正为前提，而非盲重试。

## 4. 开放控制保留（不可晋升弃权）

- **发生了什么：** 两个 Lean 开放问题控制家族被呈现给模型。两者均被保留为**弃权**（`openControlPromotion: 0`）。
- **为何重要：** 开放控制是无可执行规约的任务。若模型"解决"了它，那将是静默放行或金标走私。本包策略门拒绝开放控制晋升；计数为零，检查器强制之。
- **信号类型：** 稳定负向 + 安全（系统正确拒绝在未解问题上过度声明）。

## 5. 合成 rehearsal 结构泄漏（自审）

- **发生了什么：** 独立审计发现 144 任务 rehearsal 仅有 15 个生成器家族（非 30）、70 行 seed 无关行、14 个重复 prompt，以及通过前生成器/预言机的公开结构泄漏。
- **处置：** rehearsal 被保留但明确标记 `confirmatoryEligible:false`。其生成器/预言机被移至被忽略的私有边界之后，且**未打包**。确认性执行在代码中硬阻断，直到存在真正的私有 30 家族 benchmark。
- **信号类型：** 反例 + 合理问题修正（工具有缺陷；缺陷被披露而非掩盖）。
