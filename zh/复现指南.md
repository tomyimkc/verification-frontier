# 复现快速入门

> **无需 GPU、网络、登录或模型凭证**即可校验本包。以下全部为确定性纯 CPU。模型接触是单独的、显式选择、需所有者授权的路径。
>
> 测试 Python：**3.12**（v2 确定性构建器亦可在 3.11+ 运行）。可选符号层需 `sympy`；无依赖路径仅需标准库。

## 1. 最快校验（≈2 分钟，仅标准库）

```bash
python3 demo.py --selfcheck                  # 验证器、覆盖、回合契约
python3 v2/stage_a.py --check                # 24 家族计划（8/8/8）
python3 v2/build_stage_a_result.py --check   # 真实 23/24 结果绑定
python3 verify_bundle.py                     # 确定性 ZIP 完整性 + 声明边界
```

四项均输出 `PASS`/`SELF-CHECK PASSED` 即核心证据完好。

## 2. 完整确定性套件（带 venv，≈2 分钟）

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt        # sympy（可选符号层）
.venv/bin/pip install -r requirements-docs.txt   # pypdf + reportlab（PDF 构建/校验）
./run_all.sh
```

`run_all.sh` 依次运行：`demo.py --selfcheck` + 48 确定性环境测试；**152 个 v2 测试**（含 12 个新的 stage-a-result 测试）；hosted-demo 逻辑 + 健康检查（0 网络 / 0 模型）；双语四页 PDF 构建；确定性 ZIP 构建 + `verify_bundle.py`。期望：每行报告 PASS / OK；最终 ZIP SHA-256 与 `dist/GOAI-AI4R-Open-Exploration.zip.sha256` 一致。

## 3. 校验确定性 ZIP 字节可复现

```bash
.venv/bin/python build_bundle.py              # 构建 #1
cp dist/GOAI-AI4R-Open-Exploration.zip /tmp/goai-build-1.zip
.venv/bin/python build_bundle.py              # 构建 #2
cmp /tmp/goai-build-1.zip dist/GOAI-AI4R-Open-Exploration.zip && echo "BYTE-IDENTICAL"
shasum -a 256 dist/GOAI-AI4R-Open-Exploration.zip
# 须与 dist/GOAI-AI4R-Open-Exploration.zip.sha256 一致
```
