# 相关工作与新颖性边界（简体中文要点）

> 英文原文：[`RELATED-WORK.md`](../RELATED-WORK.md)。

本项目不主张发明确定性验证、Agent 弃权、验证边界、受守护的验证器修改、量纲分析、SymPy、Lean 或 RLVR。

| 工作 | 相关贡献 | 本项目的区别 |
|---|---|---|
| RLVP（arXiv:2607.10474） | 可执行物理验证与连续奖励 | 无 RL 后训练声明；跨领域验证器覆盖实验 |
| EG-VAR（arXiv:2607.12650） | 内核治理推理、审计轨迹、诚实弃权 | 人类审批的可复用验证器修改 + 密封迁移 |
| Recursive Epistemic Engines | Novelty Horizon 与受守护的验证器扩展 | 无发明声明；前瞻性匹配对实证运营化 |
| AgentAbstain（arXiv:2607.10059） | 成对作答/弃权评估 | 目标是扩展可执行科学覆盖，而非仅弃权 |

最高的新颖性风险是围绕 Novelty Horizon 的受守护验证器扩展。因此可辩护的贡献是**前瞻性实证证据与可复现工具**，而非发明。即使"优先"或"首次"声明也予以避免。

详细的相关工作定位与新颖性边界见 [`PROJECT.md`](../PROJECT.md) §11 与 [`RELATED-WORK.md`](../RELATED-WORK.md)。
